# Security Policy

## Supported versions

While the package is pre-1.0, the latest released `0.x` minor receives security fixes. This table will be updated after `1.0`.

| Version       | Supported |
|---------------|-----------|
| 0.x (latest)  | ✅        |

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do **not** open a public issue or pull request.

Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability): open the repository's **Security** tab → **Report a vulnerability**.

> Maintainers: enable this under *Settings → Code security and analysis → Private vulnerability reporting*.

We aim to acknowledge reports within a few working days and will keep you updated on the fix and disclosure timeline.
